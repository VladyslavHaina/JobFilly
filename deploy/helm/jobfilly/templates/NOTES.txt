JobFilly {{ .Chart.AppVersion }} is installed as {{ include "jobfilly.fullname" . }} in {{ .Release.Namespace }}.

{{- if .Values.ingress.enabled }}

Open {{ include "jobfilly.publicUrl" . }}
(the Ingress for {{ .Values.ingress.host }}; point its DNS at your ingress controller).
{{- else }}

Reach it with a port-forward, then open {{ include "jobfilly.publicUrl" . }}:

  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "jobfilly.fullname" . }} {{ .Values.port }}:{{ .Values.service.port }}

If you open it at another address, set config.publicUrl to it: sign-in only accepts requests
from PUBLIC_URL's origin.
{{- end }}

The pods turn ready once the database is reachable and migrated (they migrate at start).
Watch them with:

  kubectl --namespace {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
{{- if and (not .Values.existingSecret) (or (not (include "jobfilly.databaseUrl" .)) (not .Values.secret.secretKey)) }}

WARNING: the server won't start without its secret settings. Set them, then upgrade:
{{- if not (include "jobfilly.databaseUrl" .) }}
  --set secret.databaseUrl=postgres://user:password@host:5432/jobfilly  (or postgresql.enabled=true)
{{- end }}
{{- if not .Values.secret.secretKey }}
  --set secret.secretKey=$(openssl rand -base64 32)  (keep it: it encrypts stored passwords and keys)
{{- end }}
or name a Secret of your own with existingSecret.
{{- end }}
{{- if .Values.postgresql.enabled }}

The bundled PostgreSQL is for trying JobFilly out: no backups, one volume. Use an external
database (secret.databaseUrl) for anything you want to keep.
{{- end }}
